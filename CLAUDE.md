# Writing rules

- Cite every real-world claim with a Markdown footnote `[^id]` linking its source (primary first), listed under `## Sources` at file end; soften or cut anything unsourced. Fictional Mehra & Cole details need no source.
- Structure every chapter like `book/02-prologue-what-a-forward-deployed-engineer-is.md`: main point + structure tree up top, then each section as short lead paragraph → bold-labelled bullet pointers → short "so what" paragraph, ending with reference tables.
